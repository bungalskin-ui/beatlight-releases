# BeatLight

VJ-Software für Leinwände und LED-Wände – reagiert auf Musik (BPM, Beat), Art-Net DMX, Logos, Videos, Effekte, Szenen, mehrere Bildschirme, Handy-Fernbedienung und Stream Deck.

Erstellt von Norbert Bungalski.

## Herunterladen

Auf der Seite **[Releases](../../releases/latest)** das passende Paket laden:

| Dein Gerät | Datei |
|---|---|
| Mac mit M1, M2, M3 oder M4 | `BeatLight-Mac-AppleSilicon-M1-M2-M3-M4.zip` |
| Älterer Mac (Intel) | `BeatLight-Mac-Intel.zip` |
| Windows | `BeatLight-Windows.zip` |

Welcher Mac? Apfel-Menü → „Über diesen Mac“: steht dort *Apple M…*, nimm die Apple-Silicon-Datei, bei *Intel* die Intel-Datei.

## Installieren

**Mac**
1. Zip entpacken, `BeatLight` in den Ordner **Programme** ziehen.
2. Beim ersten Öffnen erscheint „Nicht geöffnet“: Systemeinstellungen → Datenschutz & Sicherheit → unten **„Trotzdem öffnen“**.
   (Alternativ im Terminal: `xattr -cr /Applications/BeatLight.app`)

**Windows**
1. Zip entpacken, den Ordner `BeatLight` an einen beliebigen Platz legen, der beschreibbar ist (z. B. Dokumente oder Desktop – nicht „C:\Programme“).
2. `BeatLight.exe` starten. Bei der Meldung „Der Computer wurde geschützt“: **Weitere Informationen → Trotzdem ausführen**.

## Updates

BeatLight prüft beim Start selbst, ob es eine neue Version gibt. Dann erscheint oben der Knopf **⬆ Update** – ein Klick lädt die neue Version, BeatLight startet neu, fertig. Projekte und Einstellungen bleiben erhalten.
Manuell: **Projekt ▾ → Nach Updates suchen**.
